# Git-versionhallinta tehtävät

#### Kurssi: Git-versionhallinta + kurssi_koodi
#### Tekijä: Oskari Oksanen
#### Repositorion sisältö:
Tässä repositoriossa on git-versionhallinta -kurssin tehtävien 1-7 suoritukset. Tehtävien suoritukset ovat merkitty historiassa tehtävän numeroa vastaavalla tägillä. Tehtävissä repositorioon luotiin yksinkertainen Hello-ohjelma, jota voi tarkastella index-tiedostosta.
